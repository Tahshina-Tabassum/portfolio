# Tahshina's Personal Portfolio 🎨✨

Welcome to the personal portfolio website of **Tahshina Tabassum**—a UX Designer & Frontend Developer based in Dhaka, Bangladesh. This portfolio serves as a digital sketchbook detailing her professional work, educational background, creative hobbies, and hand-drawn sketches.

## 🌟 Key Features

*   **Premium Interactive Layout**: A responsive design built with custom animations and interactive transitions (including a playful flying birds SVG strip).
*   **The Daily Troubleshooter About Section**: A unique newspaper-themed showcase presenting academic history, bio, and key skills.
*   **Chalkboard-Style Interactive Showcase**: A dual-themed board featuring professional soft skills, fun facts, and a fully interactive sliding **Sketchbook Gallery** highlighting hand-drawn artwork.
*   **Terminal-Style Contact Form**: A customized, fully functional interactive terminal-themed message portal powered by **EmailJS** to send messages directly from the webpage.
*   **Fluid Theme Toggle**: Easily switch between a cozy retro Light Mode (`☀️`) and a sleek, immersive Dark Mode (`🌙`).

---

## 🛠️ Built With

*   **Structure**: HTML5 (Semantic and accessible markup)
*   **Styling**: Vanilla CSS3 (Custom variables, smooth flexbox/grid alignments, keyframe animations, glassmorphic navigation)
*   **Behavior**: JavaScript (Theme switching logic, typing carousel animations, interactive menu controls, and slide transitions)
*   **Email Engine**: [EmailJS](https://www.emailjs.com/) for zero-backend form handling
*   **Illustrations**: Beautiful vectors by [Storyset](https://storyset.com/)

## 🚀 Getting Started

To view the project locally:
1. Clone or download this repository.
2. Open `index.html` in any web browser of your choice.
3. (Optional) Run a simple local HTTP server (e.g. `npx serve` or Live Server extension in VS Code) for the best local testing experience.
